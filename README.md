# DAS DACH

Strona firmowa DAS DACH — pokrycia dachowe, blacharstwo, ciesielstwo i budownictwo. Sadki / Śmielin.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Ustaw domenę w `.env`:

```env
VITE_SITE_URL=https://twoja-domena.pl
```
